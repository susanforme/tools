2026-09-23。单个 agent 实现；入口接入首页与全局导航，中英双语，20 个图标使用不同颜色。

## 行为与边界

- 数学工具另行合并为
  `/math?tool=<id>`。首页与导航只保留一个数学工具箱入口；20 个旧独立路由删除，不设置重定向。切换子工具清除不适用的计算模式和精度参数。
- 文件夹与重复文件：最多 1000 个文件，单个 100 MB，总计 1
  GB；SHA-256 内容比较。空目录可显式选择。输出 JSON 报告，不自动删除任何文件。
- 编码：最多 5
  MB，支持 UTF-8、GB18030、Big5、Shift_JIS、UTF-16LE/BE、Windows-1252。支持 Unicode
  BOM 和换行转换；非法字节或有损转换拒绝写出。
- PDF 对比：两份文件各最多 20
  MB；同页位置比对，包含文字差异、双页同步滚动、叠加和像素差异。较短文件缺页显示空白和提示。未做 OCR，扫描件使用图像模式。
- PDF 拼版：最多 200 页，补齐 4 的倍数；A4/Letter、左右装订、全部/正面/背面导出，适配页面旋转。打印时按说明使用横向短边翻转。
- 脑图：标题及缩进列表，最多 300 个节点、12 级缩进。SVG 导出当前折叠状态；HTML 用原生 details 保留完整可折叠树。
- 幻灯片：最多 100 页；独立 `---` 分页，`???`
  后为演讲备注，3 个主题，全屏、独立 HTML、浏览器打印。Markdown 使用项目现有清洗逻辑，预览在沙箱 iframe 中。
- 白板：平移、缩放、画笔、矩形、箭头、便签、选择移动和删除，30 步撤销。最多 500 个对象，每笔最多 2000 点；备份大小限制保证可恢复。SVG/PNG 导出当前视窗。
- 图片描摹：最长边不超过 1000 像素再处理，2–32 色、黑白阈值和简化参数；独立 Worker 超时终止。
- 精灵图：沿用图片导入器，最长边缩至 2000 像素；导入最多 20 张，切片最多 256 帧，要求帧尺寸整除图片尺寸。输出 PNG、JSON 和含每帧 PNG 的 ZIP；支持动画预览。
- CSS 裁剪：多边形、圆、椭圆，拖动点、数字坐标、图片预览和 CSS 导出。
- 电阻：4/5/6 环、容差及温度系数、精确反向编码；SMD 支持三/四位数字和 R 小数形式，不包含 EIA-96。
- 棋钟：初始时间、Fischer 加秒、Bronstein 延时、暂停、超时终止和空格切换。按真实经过时间计算，后台计时不依赖 interval 次数。
- 钢琴：Web
  Audio 合成音色，键盘/触摸、八度、音量、最多 60 秒录制、播放和录制事件 JSON 导出；离页及失焦停止。
- 和弦：五种常用性质，音名、键位、标准调弦吉他候选指型、试听、和弦谱转调和变调夹移调；指型为和弦音组合，未做人手难度评级。
- 鼓机：4 音轨、16 步单小节、速度与摇摆、备份恢复、单声道 44.1 kHz PCM16
  WAV 导出；离页及修改节奏时停止播放。
- 习惯：每日打卡、每周目标、连续天数、91 天热图。菜单：食谱、份量、每日三餐和本周购物清单，按食材及单位汇总，不混加不同单位。
- 白板、鼓机、习惯和菜单使用项目现有本地存储与备份恢复组件，包含备份校验和多标签页写入冲突保护。
- 数独：生成时逐次验证唯一解，候选数、提示、求解和题目/答案 PDF；难度按提示数分档，不声明逻辑技巧等级。字谜支持最多 30 个词、5–30 方格、对角与反向、答案 PDF；无法放入全部词时明确报错。
