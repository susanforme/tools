# 新增 20 项本地工具（2026-09-23）

参考 [IT Tools](https://github.com/CorentinTh/it-tools) 的工具集合方式，以及 [Stirling PDF 页面操作](https://docs.stirlingpdf.com/Functionality/Page-Operations/) 的常见文档需求。核对现有页面后，将新功能合并为四个入口，每个入口五项功能。

| 入口 | 新功能 |
| --- | --- |
| `/web-diagnostics` | JSON Merge Patch 生成、网址去跟踪参数、指数退避重试计划、Docker Compose 服务依赖顺序、UTM 推广链接 |
| `/data-prep` | CSV 交叉透视、重复键冲突报告、必填/数值列检查、时间序列按日汇总、GeoJSON 线条简化 |
| `/media-finishing` | SRT/VTT 时间偏移、SVG 精确颜色替换、保留原 PDF 内容的矢量页码、立体声相位相关性、字体字符覆盖报告 |
| `/planning-calculators` | 项目关键路径、决策权重 ±20% 敏感度、考前章节倒排计划、未来十二个月订阅费用、行李占用体积估算 |

输入只在浏览器本地处理。四个工作台的当前模式写入 URL；输入文件与结果不写入 URL。CSV 以列名识别数据，采用 UTF-8，最多 2 MB / 20,000 行（计划类最多 500 KB / 5,000 行）。GeoJSON 简化仅处理 LineString / MultiLineString，容差单位为经纬度，可能改变细节，不能用于精密测绘。PDF 页码写入原文件页面，不自动识别已有页码；旋转页面需检查生成结果。音频相位报告对双声道做至多约一百万帧抽样，不能代替专业混音测量。订阅费用不做币种换算；行李体积按物品外接长方体估算，不代表实际可装入。
