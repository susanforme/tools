## 使用边界

- 个人草稿和清单存储在当前浏览器，跨浏览器或清理站点数据前应先导出备份。图像设计项目通过 JSON 文件保存与恢复。
- PDF 使用 A4 页面；打印时选择实际大小，关闭打印机额外缩放。
- 拼豆色卡采用通用自定义颜色与编号，不代表材料品牌官方色号。
- 裁切方案采用受旋转、纹理和切缝约束的直切启发式，不保证全局最优。
- 调音范围 50–1400 Hz，适合持续单音；需要麦克风权限，可调整 A4 参考频率。
- 亲戚称谓采用 relationship.js 词库，部分称谓有地域差异；复杂查询有时间限制。
- 拼音采用 pinyin-pro 词库，可手动纠正人名、多音字。
- 订阅按币种分别汇总，不自动假设汇率；日历提醒通过导出 ICS 交由日历应用管理。
- 页面在浏览器处理用户数据；首次加载部分依赖需要访问现有站点的固定版本 CDN。
