# 第三批：数据、文献、逻辑、算法与包装工具

## 实现范围

| 入口                  | 合并功能                                                                                                 | 实际边界                                                                                                                                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/data-charts`        | CSV / JSON 导入；分类求和、平均、计数、最小/最大汇总；柱状、折线、散点和饼图；SVG / PNG / 汇总 JSON 导出 | 2 MB / 5,000 行 / 50 列，100 个分组；散点最多 1,000 行。JSON 为平面对象数组，空数值不当作 0。单分类字段与单数值字段汇总。                                                                                                                       |
| `/citation-tool`      | BibTeX / RIS / CSL-JSON 转换；去重；文内引用与参考文献；原格式和文本下载                                 | Citation.js 0.9.0 官方内置 APA 7、NLM/Vancouver Citing Medicine 2nd、Cite Them Right 12th Harvard。500 KB / 300 条。按 DOI，或完整标题/作者/年份/类型/版次组合去重，保留首条。只处理导入元数据，不联网补全。Worker 可取消并在 30 秒超时后终止。 |
| `/logic-workbench`    | 真值表、布尔化简、等价检查、卡诺图、结果 JSON 导出                                                       | 最多 6 变量、1,000 字符、128 符号、32 层嵌套；卡诺图 2–4 变量。非、与、异或、或优先级明确。素蕴含项贪心覆盖保持等价，不承诺全局最短；展开更长时保留原表达式。                                                                                   |
| `/algorithm-lab`      | 冒泡/插入/选择排序；二分查找；BFS / Dijkstra；编辑网格、逐步/自动播放、操作次数对照、完整轨迹导出        | 数组最多 40 个数；8×8 网格，障碍/权重 1/5，四邻接。二分查找要求输入升序。BFS 对照按步数，Dijkstra 对照按进入格子的权重，UI 已明确单位。                                                                                                         |
| `/packaging-designer` | 开槽盒、信封、开口袋；宽高深/胶边参数；裁线与折线；SVG / PNG、原尺寸 PDF 和 A4 拼接 PDF                  | 毫米尺寸，PDF 为矢量。A4 拼接使用 190×277 mm 内容区和页坐标，打印需 100%。按薄纸计算，厚板须自行预留厚度；未做实体裁切装配验证。                                                                                                                |

模式与绘图/打印选项通过 URL 保存；输入正文为临时状态。中英文文案在
`apps/web/src/i18n/locales/batch3-analysis.ts`，namespace 为
`analysis3`。没有拆成子功能路由。
